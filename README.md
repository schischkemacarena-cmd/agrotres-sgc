# Sistema de Gestión Documental — Frigorífico Agrotres S.A. (Est. Oficial N.º 5258)

Sitio web estático conformado para publicar en **GitHub Pages (`github.io`)** con el catálogo de documentos de **Frigorífico Agrotres S.A.**:
- **4 documentos HACCP** (Análisis de Peligros Faena/Recepción y Despostada; Manuales M-10 y M-11).
- **23 Procedimientos Operativos Estandarizados** (`PE-01` a `PE-23`).
- **24 Registros y Listados** (`R-02` a `R-28.1`).

## Estructura del proyecto
```text
├── index.html
├── css/
│   └── styles.css
├── js/
│   ├── app.js
│   └── data.js
├── data/
│   └── documentos.json
└── README.md
```

## Publicar en GitHub Pages (`github.io`)
1. Subí todos los archivos de esta carpeta a un repositorio en GitHub (por ejemplo `agrotres-sgc` o `<tu-usuario>.github.io`).
2. Andá a **Settings → Pages**.
3. En **Build and deployment**, seleccioná **Deploy from a branch**, elegí la rama `main` y la carpeta `/ (root)`, y guardá.
4. En unos minutos quedará disponible en `https://<tu-usuario>.github.io/<repo>/` (o `https://<tu-usuario>.github.io/`).
